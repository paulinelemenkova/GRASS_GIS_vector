# GRASS GIS Scripts — Vector Data Processing and Thematic Mapping of Burundi

GRASS GIS shell scripts used to produce the figures in the peer-reviewed article by Polina Lemenkova (published in English and French). The scripts process vector geospatial data and satellite imagery for thematic land-cover mapping of Burundi, East Africa.

## Contents
GRASS GIS shell scripts for vector geospatial data processing — shapefile import (v.in.ogr), vector metadata and topology (v.info), attribute-table queries on DBF databases (v.db.select, db.select, db.columns, db.describe), vector styling by attribute (v.colors) and display (d.vect, d.legend.vect) — applied to land-cover data of Burundi, together with a Landsat satellite-image mosaic and classification workflow.
